# 💰 Finance Fragment

Um sistema de controle financeiro pessoal, construído do zero como parte da minha jornada de aprendizado em programação.

---

## 📖 Sobre o projeto

O **Finance Fragment** nasceu de uma necessidade real: eu queria uma ferramenta simples para organizar minha vida financeira sem depender de planilhas confusas ou aplicativos cheios de funcionalidades que eu não uso.

A ideia é ter um lugar onde eu possa registrar o que entra, o que sai, o que foi parcelado, quanto ainda devo e quando vou me livrar de cada dívida — sem ter que "pensar" ou "organizar tudo de novo" no fim do mês.

Mais do que um software, este projeto é um **registro público da minha evolução como programador**. Cada funcionalidade aqui representa um conceito que eu aprendi, pratiquei e apliquei.

---

## ✅ Funcionalidades atuais (v0.1)

Versão inicial, focada no fluxo básico de entrada → processamento → saída:

- [x] Solicita o nome do usuário
- [x] Solicita o valor de uma receita
- [x] Solicita o valor de uma despesa
- [x] Calcula o saldo (receita − despesa)
- [x] Exibe um relatório formatado no terminal

Funcionalidades planejadas, que serão implementadas conforme eu avanço nos estudos:

### Curto prazo
- [ ] Múltiplas receitas e despesas
